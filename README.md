# Task Management App

## Features
- Add Task
- Edit Task
- Delete Task
- Mark Task Complete
- Responsive UI
- REST API Integration

## Tech Stack
- React.js
- Node.js
- Express.js
- MongoDB

## Setup

### Frontend

```bash
cd frontend
npm install
npm start
```

### Backend

```bash
cd backend
npm install
npm start
```

## Note

MongoDB Atlas connection may require proper DNS/network configuration depending on ISP/local environment.
